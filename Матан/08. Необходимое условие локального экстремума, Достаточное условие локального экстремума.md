## Теорема: 

Пусть 
$$ \Large
f \in C([a;b]) \quad c \in (a;b) \quad \exists f'(c) \quad c \ - \ \text{ лок. экстремум }
$$

$$ \Large
 \Rightarrow \text{по теореме Ферма(1.58)} \quad f'(c)=0
$$
$$ $$
$$ \Large
\forall x \in (a;b) \quad \exists f'(x) \ \text{и} \ f'(c) = 0
$$

#### 1)минимум
$$ \Large
 \ f'(x)<0 \ \text{если } x<c,\quad f'(x)>0 \ \text{если } x>c
$$
$$ \Large
\Rightarrow f \downarrow \downarrow \ \text{на } [a;c],\quad f \uparrow \uparrow \ \text{на } [c;b]
$$
$$ \Large
x_1<c \Rightarrow f(x_1)> f(c),\quad c<x_2 \Rightarrow f(c)< f(x_2)
$$
$$ \Large
\Rightarrow c \text{ — лок. минимум}
$$


#### 2)максимум
$$ \Large
 \ f'(x)>0 \ \text{если } x<c,\quad f'(x)<0 \ \text{если } x>c
$$
$$ \Large
\Rightarrow f \uparrow \uparrow \ \text{на } [a;c],\quad f \downarrow \downarrow \ \text{на } [c;b]
$$
$$ \Large
x_1<c \Rightarrow f(x_1)< f(c),\quad c<x_2 \Rightarrow f(c)> f(x_2)
$$
$$ \Large
\Rightarrow c \text{ — лок. максимум}
$$

#### 3)нет экстремума(аналогично, если производная <0 с обоих сторон)
$$ \Large
 \ f'(x)>0 \ \text{если } x>c,\quad f'(x)>0 \ \text{если } x>c
$$
$$ \Large
\Rightarrow f \uparrow \uparrow \ \text{на } [a;b] \ \text{по теореме о строгом возрастании функции(2.4)}
$$
$$ \Large
x_1<c<x_2 \Rightarrow f(x_1) < f(c) < f(x_2)
$$
$$ \Large
\Rightarrow c \text{ не экстремум}
$$
